## Sobre o projeto para uso pessoal 

O **SATURIA** é um aplicativo mobile de organização pessoal desenvolvido para centralizar o gerenciamento de tarefas, compromissos e prazos em um único lugar.

O projeto busca oferecer uma experiência simples, intuitiva e organizada, permitindo acompanhar responsabilidades acadêmicas e pessoais de maneira prática no dia a dia.

Mais do que um organizador, o SATURIA é um projeto de aprendizado e aplicação prática de tecnologias modernas do desenvolvimento de software, envolvendo desenvolvimento mobile, construção de APIs, modelagem de dados e qualidade de software.

## 🎯 Objetivo

Centralizar a organização da rotina acadêmica, facilitando o acompanhamento de atividades, prazos, calendário e compromissos.

## ✨ Funcionalidades planejadas

- [ ] Cadastro e autenticação de usuários
- [ ] Gerenciamento de tarefas do dia
- [ ] Organização de atividades por categorias
- [ ] Marcação de compromisso no calendário 
- [ ] Gerenciamento de compromissos com visualização em calendário (por mês, dias ou semanas)
- [ ] Painel inicial com resumo das atividades (da semana, do dia ou do mês)
- [ ] Diário personalizável   
- [ ] Interface mobile com tema escuro ou claro

## 🏗️ Arquitetura e organização

O back-end será desenvolvido utilizando uma arquitetura de **monólito modular**, com responsabilidades organizadas em módulos independentes.

A solução contará com a separação entre três componentes principais:

- **Aplicativo mobile:** responsável pela interface e interação com o usuário.
- **API:** responsável pelas regras de negócio, processamento e comunicação entre as camadas.
- **Banco de dados:** responsável pela persistência e organização das informações.

Considerando que o SATURIA é um projeto de uso individual, voltado à organização de compromissos e atividades pessoais, a arquitetura busca equilibrar simplicidade, manutenibilidade e organização, evitando complexidade desnecessária.
